Система управления заказами для консалтинговой компании
Описание проекта

Инструмент автоматизации рабочих процессов, построенный на базе Telegram-бота и веб-интерфейса аналитики. Решение предназначено для упорядочивания обработки заявок, контроля их жизненного цикла и оценки продуктивности сотрудников.

Задачи проекта
Создание единого цифрового пространства для работы с клиентскими заявками.
Обеспечение полной видимости этапов выполнения заказов.
Ускорение реакции на входящие обращения.
Повышение качества взаимодействия с клиентами за счет оперативного информирования.
Функциональные возможности
Управление через чат в мессенджере без необходимости установки дополнительных программ.
Веб-панель мониторинга с графическим отображением метрик эффективности.
Синхронизация данных: информация обновляется ежеминутно.
Локальное хранилище информации о сделках в формате таблицы CSV.
Разграничение доступа: каждый сотрудник видит только закрепленные за ним задачи.
Необходимые условия для запуска
Интерпретатор Python версии 3.9 или новее.
Зарегистрированный аккаунт бота (получается у @BotFather).
Стабильное подключение к сети.

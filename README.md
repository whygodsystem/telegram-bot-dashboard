# Управление заказами в консалтинговой компании

## Описание проекта

Это решение автоматизирует обработку заказов для консалтинговой фирмы. Оно включает Telegram-бота на Python и интерактивную панель аналитики. Система упрощает отслеживание статусов, назначение менеджеров и анализ эффективности.

### Цель

Создать удобный инструмент для прозрачного управления заказами, сокращения времени реакции на заявки и повышения качества обслуживания клиентов.

### Основные возможности

- Telegram-бот (библиотека `python-telegram-bot`) для оперативного управления заказами.
- Панель управления на базе Dash и Plotly с графиками и фильтрами.
- Автообновление дашборда каждую минуту.
- Хранение данных в CSV-файле (простота и переносимость).
- Работа с несколькими менеджерами, фильтрация по ним.

---

## Требования к окружению

- Python 3.8 или новее.
- Созданный Telegram-бот (получить токен у @BotFather).
- Доступ в интернет для установки пакетов.

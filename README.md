# Система управления заказами для консалтинга

## О чём этот проект

Это приложение помогает консалтинговой компании вести заказы через Telegram-бота и наглядную веб-панель. Бот позволяет быстро добавлять, править и удалять заявки, а дашборд показывает статистику по менеджерам и статусам.

### Для чего это нужно

Чтобы сделать работу с заказами прозрачной, сократить время обработки запросов и повысить качество обслуживания клиентов.

### Что умеет система

- Телеграм-бот (на `python-telegram-bot`) для всех операций с заказами.
- Интерактивная панель на Dash с графиками и фильтрами.
- Автоматическое обновление панели каждую минуту.
- Все данные хранятся в CSV – удобно для бэкапов и ручного редактирования.
- Можно фильтровать отчёты по каждому менеджеру.

---

## Что нужно для запуска

- Python 3.8 или новее.
- Токен бота, полученный через [@BotFather](https://t.me/botfather).
- Подключение к интернету для установки библиотек.
